# Setup Avatar untuk Dodge Game 🎮

## Langkah Setup:

1. **Siapkan foto avatar kamu** (format: JPG, PNG, atau WEBP)
2. **Crop foto jadi 1:1 (square/kotak)**
3. **Rename foto jadi `avatar.png`**
4. **Copy ke folder `birthday-premium/public/`**

## Recommended:
- Size: 200x200px atau 500x500px
- Format: PNG (dengan background transparan lebih bagus)
- Ratio: 1:1 (kotak)

## Jika belum ada foto:
- Emoji 😊 akan muncul sebagai placeholder
- Game tetap bisa dimainkan normal

## Path file:
```
birthday-premium/
  └── public/
      └── avatar.png  <-- taruh foto disini
```

Setelah file ditaruh, refresh browser untuk lihat perubahan!
